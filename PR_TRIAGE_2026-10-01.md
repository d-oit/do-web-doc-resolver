   (GHSA-q2hr-2g5m-vhwr `< 5.0.12`). The PR's `5.0.12` bump clears all three, but is

2. **#640's effective diff is 2 files, not 13.** 9 `dtolnay/rust-toolchain` SHA bumps

## Verification notes

- "Effective diff" = `git diff <main-HEAD> refs/pr/<n>`, i.e. the PR head tree vs
  current `main`. Used because a stale branch's own diff overstates its content.
- Peer-dependency claims confirmed against the npm registry, not inferred:
  `npm view @vitest/coverage-v8@5.0.1 peerDependencies`.
- Advisory ranges confirmed via the GitHub advisory API (`/advisories?affects=…`).
- `commitlint` failures read from the actual failed run logs (`gh run view --log-failed`).
